## ADDED Requirements

### Requirement: 그래프를 시각화 명령으로 렌더링한다
시스템은 `make show-map` 명령을 통해 Pioneer가 발견한 노드 그래프를 시각화해야 한다.

#### Scenario: 개발자가 그래프를 렌더링
- **WHEN** 개발자가 `make show-map` 명령을 실행할 때
- **THEN** 시스템은 DB에서 노드와 엣지를 조회하여 시각화 결과를 생성한다

#### Scenario: 빈 그래프 처리
- **WHEN** DB에 아직 노드가 없는 상태에서 명령을 실행할 때
- **THEN** 시스템은 "No nodes found" 메시지를 표시한다

### Requirement: 사이트별로 노드를 그룹화한다
시각화는 노드를 출처 사이트(domain)별로 구분하여 표시해야 한다.

#### Scenario: 여러 사이트의 노드 표시
- **WHEN** 여러 사이트에서 크롤된 노드가 있을 때
- **THEN** 시스템은 각 사이트를 명확히 구분하여 노드를 그룹화한다

#### Scenario: 사이트 라벨 표시
- **WHEN** 그래프를 렌더링할 때
- **THEN** 각 사이트 그룹에는 도메인 이름이 표시된다

### Requirement: 노드 간 연결 관계를 표시한다
시각화는 노드 간 엣지를 보여줘야 한다.

#### Scenario: 링크 엣지 표시
- **WHEN** 두 노드 간에 엣지가 존재할 때
- **THEN** 시스템은 방향성 있는 연결선을 표시한다

### Requirement: 파싱 스크립트 존재 여부를 표시한다
시각화는 각 노드에 대해 Harvester 파싱 스크립트가 구현되었는지 표시해야 한다.

#### Scenario: 스크립트가 있는 노드와 없는 노드 구분
- **WHEN** 노드에 대응하는 Harvester 스크립트가 존재할 때와 없을 때
- **THEN** 시스템은 두 상태를 시각적으로 구분하여 표시한다

#### Scenario: 스크립트 커버리지 통계
- **WHEN** 그래프를 렌더링할 때
- **THEN** 시스템은 전체 노드 대비 스크립트가 있는 노드의 비율을 표시한다

### Requirement: 노드 메타데이터를 표시한다
시각화는 각 노드의 주요 정보를 보여줘야 한다.

#### Scenario: 노드 정보 표시
- **WHEN** 노드를 렌더링할 때
- **THEN** 시스템은 노드의 타입과 URL 일부를 표시한다

#### Scenario: 방문 통계 표시
- **WHEN** 노드에 방문 기록이 있을 때
- **THEN** 시스템은 방문 횟수와 성공/실패 비율을 표시한다

### Requirement: 출력 형식을 선택할 수 있다
시스템은 브라우저 기반 또는 이미지 파일 형태로 그래프를 출력해야 한다.

#### Scenario: HTML 출력
- **WHEN** 개발자가 기본 명령을 실행할 때
- **THEN** 시스템은 브라우저에서 열리는 대화형 HTML 파일을 생성한다

#### Scenario: PNG 형식 출력
- **WHEN** 개발자가 PNG 형식을 지정할 때
- **THEN** 시스템은 PNG 이미지 파일로 그래프를 저장한다

#### Scenario: SVG 형식 출력
- **WHEN** 개발자가 SVG 형식을 지정할 때
- **THEN** 시스템은 확대/축소 가능한 SVG 파일을 생성한다
