## ADDED Requirements

### Requirement: 미디어 파일을 업로드한다
시스템은 이미지, 음원, 비디오 파일을 업로드하고 저장할 수 있어야 한다(SHALL).

#### Scenario: 이미지 업로드 성공
- **WHEN** 인증된 유저가 JPEG/PNG/GIF/WebP 이미지 파일을 업로드하면
- **THEN** 파일이 스토리지에 저장되고, 접근 가능한 URL이 반환된다

#### Scenario: 오디오 업로드 성공
- **WHEN** 인증된 유저가 MP3/WAV/OGG/FLAC 오디오 파일을 업로드하면
- **THEN** 파일이 스토리지에 저장되고, 접근 가능한 URL이 반환된다

#### Scenario: 비디오 업로드 성공
- **WHEN** 인증된 유저가 MP4/WebM 비디오 파일을 업로드하면
- **THEN** 파일이 스토리지에 저장되고, 접근 가능한 URL이 반환된다

#### Scenario: 허용되지 않은 파일 형식
- **WHEN** 허용 목록에 없는 파일 형식을 업로드하면
- **THEN** 유효성 검사 오류가 반환된다

#### Scenario: 파일 크기 초과
- **WHEN** 제한 크기를 초과하는 파일을 업로드하면 (이미지 10MB, 오디오 50MB, 비디오 100MB)
- **THEN** 파일 크기 초과 오류가 반환된다

#### Scenario: 미인증 유저는 업로드할 수 없다
- **WHEN** 미인증 상태에서 파일 업로드를 요청하면
- **THEN** 인증 오류가 반환된다

---

### Requirement: 미디어 타입을 자동 감지한다
시스템은 업로드된 파일의 MIME 타입을 기반으로 미디어 타입(image/audio/video)을 자동 분류해야 한다(SHALL).

#### Scenario: MIME 타입 기반 자동 분류
- **WHEN** 파일이 업로드되면
- **THEN** 업로드된 파일의 실제 형식을 검증하여 미디어 타입(image/audio/video)을 결정한다

#### Scenario: MIME 타입 위조 방지
- **WHEN** Content-Type과 실제 파일 내용이 일치하지 않으면
- **THEN** 유효성 검사 오류가 반환된다

---

### Requirement: 사전 정의된 태그 목록을 제공한다
시스템은 카테고리별로 그룹핑된 사전 정의 태그 목록을 제공해야 한다(SHALL).

#### Scenario: 전체 태그 목록 조회
- **WHEN** 태그 목록을 요청하면
- **THEN** 카테고리별로 그룹핑된 태그가 표시 순서대로 반환된다

#### Scenario: 태그 검색
- **WHEN** 키워드로 태그를 검색하면
- **THEN** 이름이 키워드와 부분 일치하는 태그가 반환된다

#### Scenario: 카테고리별 필터
- **WHEN** 특정 카테고리의 태그를 요청하면
- **THEN** 해당 카테고리에 속한 태그만 반환된다

---

### Requirement: 핀에 사전 정의 태그를 연결한다
시스템은 핀 생성 시 사전 정의된 태그만 선택할 수 있어야 한다(SHALL). 자유 입력 태그는 허용하지 않는다.

#### Scenario: 유효한 태그 연결
- **WHEN** 존재하는 태그 ID 목록으로 핀을 생성하면
- **THEN** 핀과 태그가 연결된다

#### Scenario: 존재하지 않는 태그 거부
- **WHEN** 존재하지 않는 태그 ID를 포함하여 핀을 생성하면
- **THEN** 유효성 검사 오류가 반환된다

#### Scenario: 태그 개수 제한
- **WHEN** 태그가 없거나 10개를 초과하여 핀 생성을 요청하면
- **THEN** 유효성 검사 오류가 반환된다

## MODIFIED Requirements

### Requirement: 외부 URL을 핀으로 저장한다
시스템은 인증된 유저가 미디어 파일을 핀으로 저장할 수 있어야 한다(SHALL). 미디어 파일(이미지/음원/비디오)이 필수이며, URL은 원본 출처 링크로 선택 사항이다. 핀은 소유권 주장이 아닌 큐레이션이다.

#### Scenario: 유효한 핀 생성
- **WHEN** 인증된 유저가 미디어 파일과 태그를 포함하여 핀 생성을 요청하면
- **THEN** 미디어가 업로드되고, 핀이 생성되고, 생성된 핀 정보가 반환된다

#### Scenario: 미디어 파일은 필수이다
- **WHEN** 미디어 파일 없이 핀 생성을 요청하면
- **THEN** 유효성 검사 오류가 반환된다

#### Scenario: URL은 선택이다
- **WHEN** URL 없이 미디어 파일과 태그만으로 핀 생성을 요청하면
- **THEN** 정상적으로 핀이 생성된다

#### Scenario: URL과 미디어를 함께 제출
- **WHEN** 미디어 파일과 URL을 모두 포함하여 핀 생성을 요청하면
- **THEN** 핀이 생성되고, URL이 원본 출처로 저장된다

#### Scenario: 태그는 사전 정의 태그에서 선택한다
- **WHEN** 사전 정의 태그 ID 목록으로 핀 생성을 요청하면
- **THEN** 해당 태그가 핀에 연결된다

#### Scenario: 같은 URL을 여러 유저가 핀할 수 있다
- **WHEN** 이미 다른 유저가 핀한 URL로 핀 생성을 요청하면
- **THEN** 정상적으로 핀이 생성된다 (URL 유니크 제약 없음)

#### Scenario: 미인증 유저는 핀을 생성할 수 없다
- **WHEN** 미인증 상태에서 핀 생성을 요청하면
- **THEN** 인증 오류가 반환된다

---

### Requirement: 핀 목록을 필터링하여 조회한다
시스템은 태그와 미디어 타입으로 필터링된 핀 목록을 페이지네이션하여 제공해야 한다(SHALL).

#### Scenario: 태그 필터
- **WHEN** 태그로 핀 목록을 요청하면
- **THEN** 해당 태그가 연결된 핀이 반환된다

#### Scenario: 미디어 타입 필터
- **WHEN** 특정 미디어 타입(image/audio/video)으로 핀 목록을 요청하면
- **THEN** 해당 미디어 타입의 핀만 반환된다

#### Scenario: 최신순 정렬
- **WHEN** 필터 없이 핀 목록을 요청하면
- **THEN** 생성 시각 역순으로 정렬되어 반환된다

#### Scenario: 유저별 필터
- **WHEN** 특정 유저 ID로 핀 목록을 요청하면
- **THEN** 해당 유저가 핀한 작품만 반환된다
