# search — Delta Spec (fix-search-tag-match-parity)

## ADDED Requirements

### Requirement: 태그 매칭 의미의 검색어 길이 불변성
통합 검색(`GET /api/search`)의 핀 검색에서 태그 매칭은 검색어 길이와 무관하게 항상 동일한 의미를 가져야 한다(SHALL). 태그 매칭은 대소문자를 구분하지 않는 부분 일치(SHALL)이며, 검색어를 더 길게 입력했다는 이유만으로 동일 태그에 대한 매칭이 실패해서는 안 된다(SHALL NOT).

#### Scenario: 대소문자가 다른 태그가 3자 이상 검색어에서도 매칭됨
- **WHEN** `Art` 태그가 붙은 핀이 존재하고 사용자가 `q=art`(3자 이상)로 핀을 검색하면
- **THEN** 해당 핀은 태그 매칭으로 검색 결과에 포함된다

#### Scenario: 태그명의 일부만 입력해도 3자 이상 검색어에서 매칭됨
- **WHEN** `illustration` 태그가 붙은 핀이 존재하고 사용자가 `q=illust`(3자 이상)로 핀을 검색하면
- **THEN** 해당 핀은 태그 매칭으로 검색 결과에 포함된다

#### Scenario: 짧은 검색어에서 매칭되던 태그가 검색어를 늘려도 계속 매칭됨
- **WHEN** 어떤 태그가 2자 이하 검색어 `q`로 태그 매칭되어 결과에 포함되던 핀에 대해, 사용자가 그 태그명과 계속 부분 일치하는 더 긴 검색어(3자 이상)로 재검색하면
- **THEN** 해당 핀은 여전히 태그 매칭으로 검색 결과에 포함된다

### Requirement: 태그 일치 가산점의 매칭 규칙 일관성
3자 이상 검색어의 핀 검색 결과 순위 산정에서 태그 일치에 부여하는 가산점은, 결과 포함 여부를 판정하는 태그 매칭과 동일한 매칭 규칙(대소문자 무시 부분 일치)을 사용해야 한다(SHALL). 태그 매칭으로 결과에 포함된 핀이 가산점 판정에서는 태그 불일치로 취급되어서는 안 된다(SHALL NOT).

#### Scenario: 대소문자가 다른 태그 일치도 가산점을 받음
- **WHEN** `Art` 태그가 붙은 핀과 태그 매칭 없이 제목 유사도만으로 걸린 핀이 함께 있고 사용자가 `q=art`로 검색하면
- **THEN** 태그가 매칭된 핀은 태그 일치 가산점을 받아, 동일한 제목 유사도라면 태그 미일치 핀보다 앞서 정렬된다

#### Scenario: 태그 필터가 결합된 검색에서도 동일 규칙 적용
- **WHEN** 사용자가 3자 이상 검색어와 함께 `tag_ids` 필터를 지정하여 핀을 검색하면
- **THEN** 검색어-태그 매칭(포함 판정 및 가산점)은 필터가 없을 때와 동일한 대소문자 무시 부분 일치 규칙을 따른다
