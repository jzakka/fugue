## ADDED Requirements

### Requirement: 통합 검색으로 핀, 크리에이터, 보드를 찾는다
시스템은 검색어를 받아 핀, 크리에이터, 보드를 한 번에 검색하여 카테고리별로 반환해야 한다(SHALL). 유사도 기반 랭킹으로 관련성 높은 결과가 상위에 노출된다.

#### Scenario: 전체 검색
- **WHEN** 검색어와 함께 전체 카테고리 검색을 요청하면
- **THEN** 핀, 크리에이터, 보드 결과가 카테고리별로 반환된다

#### Scenario: 카테고리별 검색
- **WHEN** 특정 카테고리(핀/크리에이터/보드)를 지정하여 검색하면
- **THEN** 해당 카테고리의 결과만 페이지네이션과 함께 반환된다

#### Scenario: 검색어 없이 요청
- **WHEN** 빈 검색어로 검색을 요청하면
- **THEN** 유효성 검사 오류가 반환된다

#### Scenario: 결과 페이지네이션
- **WHEN** offset과 limit을 지정하여 검색하면
- **THEN** 해당 범위의 결과와 추가 결과 존재 여부가 반환된다

---

### Requirement: 핀 검색 시 제목과 태그를 대상으로 한다
핀 검색은 제목과 연결된 태그명을 대상으로 한다(SHALL). 태그가 검색어와 일치하는 핀은 랭킹에서 가산점을 받는다.

#### Scenario: 제목 매칭
- **WHEN** 검색어로 검색하면
- **THEN** 제목이 검색어와 유사한 핀이 유사도순으로 반환된다

#### Scenario: 태그 매칭 부스트
- **WHEN** 검색어로 검색하고, 핀 A는 제목에만 매칭되고 핀 B는 태그에 정확히 매칭되면
- **THEN** 핀 B가 핀 A보다 상위에 랭킹된다

---

### Requirement: 크리에이터 검색은 닉네임을 대상으로 한다
크리에이터 검색은 닉네임을 대상으로 한다(SHALL).

#### Scenario: 닉네임 매칭
- **WHEN** 검색어로 크리에이터를 검색하면
- **THEN** 닉네임이 검색어와 유사한 크리에이터가 반환된다

---

### Requirement: 보드 검색은 공개 보드만 대상으로 한다
보드 검색은 이름을 대상으로 하며, 공개 보드만 검색 결과에 포함된다(SHALL).

#### Scenario: 공개 보드만 검색
- **WHEN** 보드를 검색하면
- **THEN** 공개 보드만 결과에 포함된다

#### Scenario: 비공개 보드 비노출
- **WHEN** 비공개 보드가 존재하고 검색어와 일치하더라도
- **THEN** 해당 보드는 검색 결과에 포함되지 않는다

---

### Requirement: 한글 2자 이하 검색어를 처리한다
시스템은 짧은 검색어에 대해 부분 문자열 매칭으로 fallback해야 한다(SHALL).

#### Scenario: 1자 검색어
- **WHEN** 1자의 검색어로 검색하면
- **THEN** 부분 문자열 매칭으로 결과를 반환한다 (결과가 넓을 수 있으나 limit으로 제어)

#### Scenario: 2자 검색어
- **WHEN** 2자의 검색어로 검색하면
- **THEN** 부분 문자열 매칭으로 결과를 반환한다

#### Scenario: 3자 이상 검색어
- **WHEN** 3자 이상의 검색어로 검색하면
- **THEN** 유사도 기반 검색으로 결과를 반환하고 유사도순으로 정렬한다

---

### Requirement: 검색 결과를 태그로 필터링한다
시스템은 검색 결과를 사전 정의 태그로 추가 필터링할 수 있어야 한다(SHALL). 필터는 AND 조건으로 적용된다.

#### Scenario: 단일 태그 필터
- **WHEN** 검색어와 태그 하나를 지정하여 검색하면
- **THEN** 검색어 매칭 + 해당 태그가 연결된 핀만 반환된다

#### Scenario: 복수 태그 필터
- **WHEN** 검색어와 태그 여러 개를 지정하여 검색하면
- **THEN** 검색어 매칭 + 모든 태그가 연결된 핀만 반환된다

#### Scenario: 태그 필터 상한
- **WHEN** 6개 이상의 태그로 필터를 요청하면
- **THEN** 유효성 검사 오류가 반환된다

#### Scenario: 태그 필터는 핀 검색에만 적용된다
- **WHEN** 크리에이터 또는 보드 검색에 태그 필터를 지정하면
- **THEN** 태그 필터는 무시된다

---

### Requirement: 검색 결과에서 인기 태그를 집계한다
시스템은 검색 결과에서 가장 많이 사용된 태그를 집계하여 반환해야 한다(SHALL).

#### Scenario: 인기 태그 반환
- **WHEN** 검색을 실행하면
- **THEN** 검색 결과 상위 핀에 연결된 태그를 빈도순으로 집계하여 반환한다

---

### Requirement: 검색바에서 자동완성을 제공한다
시스템은 검색바에 타이핑할 때 실시간 검색 제안을 보여줘야 한다(SHALL).

#### Scenario: 자동완성 드롭다운
- **WHEN** 검색바에 3자 이상 입력 후 일정 시간이 경과하면
- **THEN** 핀, 크리에이터, 보드에서 소수의 결과를 섹션별로 드롭다운에 표시한다

#### Scenario: Enter 키로 전체 검색
- **WHEN** 검색바에서 Enter 키를 누르면
- **THEN** 전체 검색 결과 페이지로 이동한다

---

### Requirement: 검색 결과 페이지를 제공한다
시스템은 검색 결과를 카테고리별 탭으로 구분하여 표시해야 한다(SHALL).

#### Scenario: 카테고리 탭
- **WHEN** 검색 결과 페이지에 접속하면
- **THEN** 전체/핀/크리에이터/보드 탭이 표시되고, 기본 탭은 전체이다

#### Scenario: 태그 필터 칩
- **WHEN** 검색 결과가 표시되면
- **THEN** 인기 태그 기반 칩이 표시되고, 클릭 시 태그 필터가 추가된다

#### Scenario: Deep Link
- **WHEN** 검색어, 카테고리, 태그 필터가 포함된 URL로 직접 접속하면
- **THEN** 해당 조건이 적용된 검색 결과가 표시된다

---

### Requirement: 최근 검색어를 저장한다
시스템은 최근 검색어를 로컬에 저장하여 빠르게 재검색할 수 있어야 한다(SHALL).

#### Scenario: 검색어 저장
- **WHEN** 검색을 실행하면
- **THEN** 검색어가 로컬 저장소에 저장된다 (최대 보관 개수를 초과하면 가장 오래된 항목이 제거된다)

#### Scenario: 최근 검색어 표시
- **WHEN** 검색바에 포커스하고 입력이 비어있으면
- **THEN** 최근 검색어 목록이 드롭다운에 표시된다

#### Scenario: 최근 검색어 삭제
- **WHEN** 최근 검색어 항목의 삭제 버튼을 클릭하면
- **THEN** 해당 검색어가 로컬 저장소에서 제거된다
