## ADDED Requirements

### Requirement: 페이지네이션 manual-click 더보기 버튼의 로딩 표시 일관성
사용자가 명시적으로 "더보기" 버튼을 클릭한 후 다음 페이지를 불러오는 동안, 버튼 내부에 시각적 spinner를 표시한다. 같은 manual-click 카테고리(사용자 명시 클릭 기반 페이지네이션)의 다른 사용처와 시각 일관성을 유지한다.

#### Scenario: 더보기 버튼 클릭 후 로딩 in-flight
- **WHEN** 사용자가 페이지네이션 더보기 버튼을 클릭하고 다음 페이지 데이터를 불러오는 동안 로딩 in-flight 상태에 있다
- **THEN** 버튼 자식 영역에 가시적 spinner(원형 회전 시각 신호, accent 색상)가 표시된다
- **AND** 버튼은 비활성화되어 추가 클릭이 무시된다

#### Scenario: 더보기 버튼 클릭 전·로딩 완료 후
- **WHEN** 사용자가 더보기 버튼을 클릭하기 전 또는 데이터 로딩이 완료된 후 다음 페이지가 더 있다
- **THEN** 버튼 자식 영역에 "더보기" 텍스트가 표시되며 클릭 가능 상태로 돌아간다

#### Scenario: 같은 manual-click 카테고리 사용처 간 시각 일관성
- **WHEN** 사용자가 두 개 이상의 페이지에서 manual-click 기반 페이지네이션 더보기 버튼을 사용한다(예: 검색 결과 페이지, 보드 상세 페이지)
- **THEN** 두 페이지의 로딩 표시는 같은 시각 패턴(spinner 시각 신호 + 가로 중앙 정렬)을 사용하여 사용자가 페이지를 넘나들어도 같은 시각 경험을 받는다

#### Scenario: 보드 상세 페이지 더보기 버튼
- **WHEN** 보드 상세 페이지에서 사용자가 더보기 버튼을 클릭한다
- **THEN** 버튼 내 spinner가 표시되며, 검색 결과 페이지의 동일 manual-click 패턴과 같은 시각 신호를 받는다
