# feed 스펙 델타: emptystate-speech-level

## ADDED Requirements

### Requirement: 피드 빈 상태 메시지는 서비스 공통 카피 어체를 따른다

피드의 분야 필터 결과가 비어 있을 때 표시되는 빈 상태 메시지는 서비스 전반의 문장형 안내 카피와 동일한 격식 어체(합쇼체, "-습니다" 종결)로 작성되어야 한다(SHALL). 같은 빈 상태 역할을 하는 다른 표면(프로필 작품 없음, 보드 없음)의 메시지와 어체가 갈리지 않아야 한다(SHALL NOT).

#### Scenario: 분야 필터 빈 결과의 어체

- **WHEN** 사용자가 작품이 없는 분야 필터를 선택해 빈 상태가 표시되면
- **THEN** 빈 상태 메시지는 "이 분야의 작품이 아직 없습니다"로, 격식 어체(합쇼체)로 렌더된다

#### Scenario: 빈 상태 표면 간 어체 일관

- **WHEN** 피드·프로필·보드의 빈 상태 메시지를 비교하면
- **THEN** 모든 빈 상태 메시지가 동일한 격식 어체(합쇼체)로 종결되며, 특정 표면만 비격식 어체(해요체)로 갈리지 않는다
