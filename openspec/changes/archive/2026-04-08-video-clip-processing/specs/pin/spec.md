## MODIFIED Requirements

### Requirement: 비디오를 웹 표준으로 압축한다
시스템은 비디오 파일 선택 시 클라이언트에서 웹 표준(H.264 1080p)으로 재인코딩해야 한다(SHALL). 이미 최적 조건을 충족하는 비디오는 재인코딩하지 않는다(SHALL).

#### Scenario: 고해상도 비디오 다운스케일
- **WHEN** 사용자가 1080p 초과 해상도의 비디오를 선택하면
- **THEN** 1080p 이하로 다운스케일된 비디오가 설정된다

#### Scenario: 비표준 코덱 비디오 변환
- **WHEN** 사용자가 H.264/MP4가 아닌 비디오를 선택하면
- **THEN** H.264/MP4로 변환된 비디오가 설정된다 (1080p 이하면 원본 해상도 유지, 초과 시 1080p로 다운스케일)

#### Scenario: H.264 MP4이지만 크기 초과
- **WHEN** 사용자가 1080p 이하 H.264/MP4 비디오를 선택하지만 서버 크기 제한을 초과하면
- **THEN** 원본 해상도를 유지한 채 재압축하여 크기 축소를 시도한다

#### Scenario: 최적 조건 충족 비디오는 패스스루
- **WHEN** 사용자가 1080p 이하 H.264/MP4 비디오를 선택하고 서버 크기 제한 이하이며 15초 이하이면
- **THEN** 재인코딩 없이 원본 그대로 설정된다

#### Scenario: 압축 후에도 크기 초과
- **WHEN** 비디오를 재인코딩한 결과가 서버 크기 제한을 초과하면
- **THEN** 크기 초과 에러가 표시된다

#### Scenario: 브라우저가 비디오 압축을 지원하지 않는 경우
- **WHEN** 브라우저가 클라이언트 비디오 압축 기능을 지원하지 않으면
- **THEN** 최적화를 건너뛰고 원본 파일이 그대로 설정된다 (서버 크기 제한은 여전히 적용되며, 15초 초과 비디오는 서버에서 거부된다)

## ADDED Requirements

### Requirement: 비디오 길이를 최대 15초로 트리밍한다
시스템은 업로드되는 비디오의 길이를 최대 15초로 제한해야 한다(SHALL). 15초를 초과하는 비디오는 클라이언트에서 앞에서부터 15초까지 자동 트리밍한다(SHALL). 트리밍은 압축과 동시에 처리된다.

#### Scenario: 15초 이하 비디오는 트리밍하지 않는다
- **WHEN** 사용자가 15초 이하의 비디오를 선택하면
- **THEN** 트리밍 없이 기존 압축 로직만 적용된다

#### Scenario: 15초 초과 비디오 자동 트리밍
- **WHEN** 사용자가 15초 초과의 비디오를 선택하면
- **THEN** 앞에서부터 15초까지 자동 트리밍되고 압축이 적용된다

#### Scenario: 브라우저가 비디오 트리밍을 지원하지 않는 경우
- **WHEN** 브라우저가 클라이언트 비디오 트리밍 기능을 지원하지 않으면
- **THEN** 트리밍 없이 원본이 전송되고, 15초 초과 시 서버 사이드 duration 검증에서 거부된다

---

### Requirement: 비디오 duration 메타데이터를 감지한다
시스템은 비디오 파일 선택 시 클라이언트에서 duration을 감지해야 한다(SHALL).

#### Scenario: duration 감지 성공
- **WHEN** 사용자가 비디오 파일을 선택하면
- **THEN** 비디오의 총 길이(초)가 감지되어 트리밍 필요 여부 판단에 사용된다

#### Scenario: duration 감지 실패
- **WHEN** 비디오 메타데이터를 읽을 수 없으면
- **THEN** 안전하게 트리밍 대상으로 간주하고 최대 15초로 트리밍을 적용한다 (클라이언트 트리밍이 불가능한 브라우저에서는 원본이 전송되며, 서버 사이드 duration 검증에 의존한다)

---

### Requirement: 트리밍 진행 상황을 사용자에게 안내한다
시스템은 트리밍이 발생할 때 사용자에게 원본 길이와 트리밍 결과를 안내해야 한다(SHALL).

#### Scenario: 트리밍 전 안내
- **WHEN** 15초 초과 비디오가 감지되면
- **THEN** 원본 길이와 트리밍 대상 길이를 알려주는 안내가 표시된다

#### Scenario: 트리밍+압축 진행 중 상태 표시
- **WHEN** 트리밍+압축이 진행 중이면
- **THEN** 진행률과 트리밍 중임을 나타내는 상태가 표시된다

#### Scenario: 트리밍 완료 결과 표시
- **WHEN** 트리밍+압축이 완료되면
- **THEN** 트리밍과 압축 결과를 요약하는 안내가 표시된다 (길이 변경, 크기 변경 등)

---

### Requirement: 서버에서 비디오 duration을 검증한다
시스템은 서버에서 업로드된 비디오의 duration이 15초를 초과하는지 검증해야 한다(SHALL). 이는 클라이언트 검증을 우회한 경우에 대한 방어선이다.

#### Scenario: 15초 이하 비디오 통과
- **WHEN** 서버에 업로드된 비디오의 duration이 15초 이하이면
- **THEN** 정상적으로 업로드가 처리된다

#### Scenario: 15초 초과 비디오 거부
- **WHEN** 서버에 업로드된 비디오의 duration이 15초를 초과하면
- **THEN** 유효성 검사 오류와 함께 비디오 길이 초과 메시지가 반환된다

#### Scenario: duration 감지 실패 시 허용
- **WHEN** 서버에서 duration을 감지할 수 없으면
- **THEN** 파일 크기 제한만 적용하고 업로드를 허용한다 (graceful degradation)
