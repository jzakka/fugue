## ADDED Requirements

### Requirement: 폼 라벨 시각 위계 분리

폼 컨트롤(`<label>` HTML 요소)의 텍스트는 본문 텍스트보다 시각적으로 강조되어, 사용자가 폼 영역의 입력 항목 이름을 본문/입력값과 구분해 식별할 수 있어야 한다. 강조 수준은 디자인 가이드(DESIGN.md L19 'UI/Labels' 카테고리)에 명시된 weight 단계를 따른다.

#### Scenario: 폼 페이지에 진입했을 때 라벨이 본문보다 강조되어 표시된다

- **WHEN** 사용자가 폼이 포함된 페이지(예: 핀 생성, 프로필 편집)에 진입한다
- **THEN** `<label>` 요소의 텍스트는 본문 기본 weight보다 한 단계 굵게 렌더링되어 입력 항목 이름임이 시각적으로 식별된다

#### Scenario: 라벨/본문 위계가 모든 폼에 일관 적용된다

- **WHEN** 코드 SSoT에 `<label>` HTML 요소가 새로 추가되거나 기존 요소가 수정된다
- **THEN** 해당 요소는 디자인 가이드 라벨 카테고리 weight를 적용받아 다른 폼의 라벨과 동일한 위계로 렌더링된다
