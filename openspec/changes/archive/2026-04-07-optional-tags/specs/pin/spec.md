## MODIFIED Requirements

### Requirement: 핀에 사전 정의 태그를 연결한다
시스템은 핀 생성 시 사전 정의된 태그를 선택할 수 있어야 한다(SHALL). 태그는 선택 사항이며, 자유 입력 태그는 허용하지 않는다.

#### Scenario: 유효한 태그 연결
- **WHEN** 존재하는 태그 ID 목록으로 핀을 생성하면
- **THEN** 핀과 태그가 연결된다

#### Scenario: 존재하지 않는 태그 거부
- **WHEN** 존재하지 않는 태그 ID를 포함하여 핀을 생성하면
- **THEN** 유효성 검사 오류가 반환된다

#### Scenario: 태그 없이 핀 생성
- **WHEN** 태그 없이 핀 생성을 요청하면
- **THEN** 정상적으로 핀이 생성된다

#### Scenario: 태그 최대 개수 초과
- **WHEN** 10개를 초과하는 태그로 핀 생성을 요청하면
- **THEN** 유효성 검사 오류가 반환된다
