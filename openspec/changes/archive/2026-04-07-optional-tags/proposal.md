## Why

현재 핀 생성 시 태그를 1개 이상 필수로 선택해야 한다. 이는 콘텐츠 업로드 허들을 높이고, "일단 올리고 나중에 정리"하는 자연스러운 큐레이션 흐름을 막는다. Pinterest도 핀 저장 시 태그 입력을 강제하지 않는다. 태그를 선택 사항으로 바꿔 업로드 경험을 가볍게 만든다.

## What Changes

- 핀 생성 시 태그 선택을 **필수 → 선택**으로 변경
- 태그 0개로 핀 생성 허용 (최대 10개 제한은 유지)
- 프론트엔드 유효성 검사에서 태그 0개 에러 제거
- API 유효성 검사에서 태그 최소 1개 제약 제거

## Capabilities

### New Capabilities

(없음)

### Modified Capabilities

- `pin`: 핀 생성 시 태그 최소 개수 제약을 제거한다 (1~10 → 0~10)

## Impact

- **API**: `POST /api/pins` 핸들러의 태그 유효성 검사 로직 수정
- **Frontend**: `PinCreateForm` 컴포넌트의 태그 필수 검증 제거, UI에서 필수 표시(*) 제거
- **Spec**: `pin` 스펙의 태그 개수 제한 시나리오 수정
- **DB**: 변경 없음 (pin_tags는 이미 N:M 관계로 0개 허용)
