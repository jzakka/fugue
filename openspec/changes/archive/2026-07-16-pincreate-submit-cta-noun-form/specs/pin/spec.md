## ADDED Requirements

### Requirement: 핀 생성 폼 제출 버튼 라벨은 서비스 공통 제출 CTA 명사형 관례를 따른다

핀 생성 폼의 제출 버튼 유휴 라벨은 명사형("등록")으로 표기하며(SHALL), 제출 진행 중 라벨은 동일 어간의 진행형("등록 중...")을 유지한다(SHALL).

#### Scenario: 유휴 상태 제출 버튼 라벨

- WHEN 사용자가 핀 생성 화면에 진입하고 제출이 진행 중이 아닐 때
- THEN 제출 버튼 라벨은 "등록"으로 표시된다

#### Scenario: 제출 진행 중 라벨 유지

- WHEN 사용자가 제출 버튼을 눌러 제출이 진행 중일 때
- THEN 제출 버튼 라벨은 "등록 중..."으로 표시되고 버튼은 비활성화 및 busy 상태로 노출된다
