# profile (delta)

## ADDED Requirements

### Requirement: 아바타 이미지 로드 실패 시 깨진 이미지 표시를 노출하지 않는다

유저/크리에이터 아바타 이미지의 URL이 유효하지 않거나 로드에 실패하면, 화면은 브라우저의 깨진 이미지 아이콘을 노출하지 않고 해당 이미지를 숨겨야 한다(SHALL). 인접한 닉네임 등 텍스트 식별 요소는 그대로 유지된다.

#### Scenario: 프로필 헤더 아바타 로드 실패

- **WHEN** 크리에이터 프로필 페이지에서 아바타 이미지 URL이 로드에 실패하면
- **THEN** 깨진 이미지 아이콘 없이 아바타 이미지가 숨겨지고, 닉네임 등 나머지 프로필 정보는 정상 표시된다

#### Scenario: 내비게이션 바 아바타 로드 실패

- **WHEN** 로그인 유저의 내비게이션 바 아바타 이미지가 로드에 실패하면
- **THEN** 깨진 이미지 아이콘 없이 아바타가 숨겨지고, 닉네임 텍스트와 마이페이지 링크 동작은 유지된다

#### Scenario: 정상 URL 렌더 불변

- **WHEN** 아바타 이미지 URL이 정상적으로 로드되면
- **THEN** 기존과 동일한 크기·모양·테두리로 아바타가 표시된다
