# board (delta)

## ADDED Requirements

### Requirement: 보드 편집 폼은 Enter 키로 저장을 실행한다

보드 상세 화면의 보드 편집 폼에서 사용자가 이름 입력 또는 설명 입력에 포커스를 둔 채 Enter 키를 누르면, 시스템은 SHALL 저장 버튼을 누른 것과 동일하게 보드 수정 저장을 실행한다.

#### Scenario: 이름 입력에서 Enter로 저장

- **WHEN** 사용자가 보드 편집 폼의 이름 입력에 유효한 이름을 입력하고 Enter 키를 누르면
- **THEN** 보드 수정 저장이 실행되고 성공 시 편집 모드가 종료되며 변경된 이름이 반영된다

#### Scenario: 설명 입력에서 Enter로 저장

- **WHEN** 사용자가 보드 편집 폼의 설명 입력에 포커스를 두고 Enter 키를 누르면
- **THEN** 보드 수정 저장이 실행된다

#### Scenario: 빈 이름으로 Enter 시 검증 에러

- **WHEN** 사용자가 이름 입력을 비운 채 Enter 키를 누르면
- **THEN** 저장 버튼 클릭과 동일하게 이름 필수 검증 에러가 표시되고 편집 모드가 유지된다
