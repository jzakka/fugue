# fix-board-add-pin-fk-error — Proposal

## Why

보드에 핀을 추가할 때 존재하지 않는 핀 ID를 보내면 DB 외래키 오류가 그대로 500 서버 오류로 노출된다. 클라이언트는 잘못된 입력(존재하지 않는 핀)과 실제 서버 장애를 구분할 수 없어 재시도 판단이 불가능하고, 서버 오류 지표도 오염된다. (Linear NAV-1251)

## What Changes

- 보드에 핀 추가 요청에서 존재하지 않는 핀을 지정하면 서버 오류(5xx)가 아니라 클라이언트 오류(404)로 응답한다.
- 기존 동작(핀 추가 성공, 중복 추가 409, 보드 없음/타인 보드 404)은 변화 없다.

## Capabilities

### New Capabilities

(없음)

### Modified Capabilities

- `board`: "보드에 핀을 추가/제거한다" 요구사항에 존재하지 않는 핀 추가 시나리오를 추가한다 — 존재하지 않는 핀 지정은 서버 오류가 아닌 찾을 수 없음 오류로 응답해야 한다.

## Impact

- 영향 코드: 보드 핀 추가 API 핸들러 (`apps/api/internal/boards/`)
- API 계약: `POST /api/boards/{id}/pins`의 오류 응답이 존재하지 않는 핀에 대해 500 → 404로 바뀐다 (오류 경로만 변경, 성공 경로 불변)
- DB 스키마·의존성 변화 없음
