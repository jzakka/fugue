## ADDED Requirements

### Requirement: 가로 스크롤 영역의 스크롤바 가시성 제어
가로 스크롤이 가능한 UI 영역(미디어 타입 필터 탭·인기 태그 칩·태그 카테고리 탭 등)에서 OS 기본 가로 스크롤바를 숨기는 디자인 토큰 utility class를 제공한다. 가로 스크롤 자체 동작(터치 스와이프, 키보드 화살표, 휠 가로 스크롤)은 유지한다.

#### Scenario: 가로 스크롤이 가능한 필터 영역
- **WHEN** UI 컴포넌트가 `overflow-x-auto`로 가로 스크롤이 가능한 영역을 표현하고, 작성자가 OS 기본 가로 스크롤바를 노출하지 않으려는 의도로 해당 영역에 스크롤바 가시성 제어 utility class를 부여한다
- **THEN** 해당 영역은 모든 주요 데스크톱 브라우저(Chrome·Safari·Firefox·Edge)와 모바일 브라우저에서 OS 기본 가로 스크롤바가 노출되지 않는다

#### Scenario: 가로 스크롤 동작 유지
- **WHEN** 스크롤바 가시성 제어 utility class가 적용된 영역에서 사용자가 가로 스크롤을 시도한다(터치 스와이프, 트랙패드 가로 스와이프, 시프트+휠, 키보드 화살표 등)
- **THEN** 가로 스크롤이 정상적으로 동작하여 영역의 자식 콘텐츠가 가로로 이동한다

#### Scenario: 메인 피드 미디어 타입 필터
- **WHEN** 메인 피드 페이지의 미디어 타입 필터 영역이 렌더링된다
- **THEN** 해당 영역에 OS 기본 가로 스크롤바가 노출되지 않으며, 가로 스크롤은 정상 동작한다

#### Scenario: 메인 피드 인기 태그 칩
- **WHEN** 메인 피드 페이지의 인기 태그 칩 영역이 렌더링된다
- **THEN** 해당 영역에 OS 기본 가로 스크롤바가 노출되지 않으며, 가로 스크롤은 정상 동작한다

#### Scenario: 검색 페이지 카테고리 탭
- **WHEN** 검색 페이지의 카테고리 탭(전체·핀·크리에이터·보드) 영역이 렌더링된다
- **THEN** 해당 영역에 OS 기본 가로 스크롤바가 노출되지 않으며, 가로 스크롤은 정상 동작한다

#### Scenario: 검색 페이지 인기 태그 칩
- **WHEN** 검색 페이지의 인기 태그 칩 영역이 렌더링된다

#### Scenario: 핀 등록 폼 태그 카테고리 탭
