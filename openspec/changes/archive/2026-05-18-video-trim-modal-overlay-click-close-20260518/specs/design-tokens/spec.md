## ADDED Requirements

### Requirement: 모달 dialog의 마우스 닫기 경로는 dim 영역 클릭으로 일관되게 동작한다

플랫폼의 모달 dialog 컴포넌트는 dim된 overlay 영역(modal 패널 바깥의 배경) 클릭으로 닫히는 마우스 사용자 닫기 경로를 일관되게 제공해야 한다(SHALL). 패널 내부 클릭은 닫지 않는다(MUST NOT). 사용자의 진행 중 드래그 인터랙션이 있는 모달은 드래그 컨텍스트 중 우발 닫힘으로부터 보호되어야 한다(SHALL).

#### Scenario: dim 영역 마우스 클릭으로 모달이 닫힌다

- **WHEN** 사용자가 모달 dialog가 열린 상태에서 패널 바깥 dim 영역을 마우스로 클릭할 때
- **THEN** 모달이 닫히고 dismiss 콜백이 호출된다

#### Scenario: 모달 패널 내부 클릭은 모달을 닫지 않는다

- **WHEN** 사용자가 모달 dialog가 열린 상태에서 패널 내부(헤더 · 본문 · 컨트롤)를 클릭할 때
- **THEN** 모달은 닫히지 않는다
- **AND** 클릭된 컨트롤의 고유 동작은 정상 처리된다

#### Scenario: 드래그 인터랙션 중에는 dim 영역 클릭이 모달을 닫지 않는다

- **WHEN** 사용자가 모달 내부에서 드래그 인터랙션(예: 비디오 트림 핸들 · window 드래그)을 진행 중일 때
- **AND** 마우스 포인터가 dim 영역으로 빠지면서 클릭이 발생할 때
- **THEN** 모달은 닫히지 않는다
- **AND** 드래그 종료 후 명시적 dim 클릭은 정상적으로 모달을 닫는다
