## MODIFIED Requirements

### Requirement: 연관 작품을 제공한다
시스템은 작품 상세 페이지에서 유사한 작품 목록을 제공해야 한다(SHALL). 태그 일치도와 미디어 타입을 기준으로 연관성을 판단하되, 태그 매칭 결과가 부족하면 다단계 fallback으로 결과를 채운다.

#### Scenario: 태그가 겹치는 연관 작품
- **WHEN** 특정 작품의 연관 작품을 요청하면
- **THEN** 태그가 겹치는 작품이 일치도 순으로 반환된다

#### Scenario: 동일 미디어 타입 우선
- **WHEN** 연관 작품이 여러 미디어 타입에 걸쳐 있으면
- **THEN** 같은 미디어 타입의 작품이 우선적으로 표시된다

#### Scenario: 자기 자신 제외
- **WHEN** 연관 작품을 조회하면
- **THEN** 조회 대상 작품 자체는 결과에 포함되지 않는다

#### Scenario: 최대 개수 제한
- **WHEN** 연관 작품을 조회하면
- **THEN** 최대 10개까지 반환된다

#### Scenario: 태그 매칭 결과가 부족하면 같은 미디어 타입으로 보충한다
- **WHEN** 태그 매칭 결과가 최대 개수에 미달하면
- **THEN** 같은 미디어 타입의 최신 작품으로 나머지를 채운다

#### Scenario: 같은 미디어 타입으로도 부족하면 최신 작품으로 보충한다
- **WHEN** 태그 매칭과 같은 미디어 타입 결과를 합쳐도 최대 개수에 미달하면
- **THEN** 미디어 타입과 무관한 최신 작품으로 나머지를 채운다

#### Scenario: 태그가 없는 작품의 연관 작품
- **WHEN** 태그가 하나도 없는 작품의 연관 작품을 요청하면
- **THEN** 같은 미디어 타입의 최신 작품부터 시작하여 fallback 결과가 반환된다

#### Scenario: 이미 포함된 작품은 중복되지 않는다
- **WHEN** fallback 단계에서 작품을 보충할 때
- **THEN** 이전 단계에서 이미 포함된 작품은 제외된다

#### Scenario: API가 에러를 반환해도 핀 상세 페이지는 정상적으로 표시된다
- **WHEN** 연관 작품 API 호출이 실패하면
- **THEN** 핀 상세 페이지는 연관 작품 섹션 없이 정상적으로 표시되고, 에러는 서버 로그에 기록된다
