## ADDED Requirements

### Requirement: 핀 생성 폼 미디어 카테고리 라벨 시각 위계 분리

핀 생성 폼의 파일 업로드 후 메타 정보 영역에서 작품의 미디어 카테고리를 노출하는 라벨은 같은 메타 영역의 다른 텍스트(파일명 · trim 정보 · 사이즈 비교)와 시각 위계가 분리되어야 한다. 미디어 카테고리 라벨은 디자인 시스템의 'tags, category labels' 카테고리에 속하며, 같은 영역의 meta 텍스트(파일명 등)는 'creator name, meta' 카테고리에 속해 한 단계 위의 글자 크기를 유지한다.

#### Scenario: 핀 생성 폼 메타 영역 미디어 카테고리 라벨이 메타 텍스트보다 작게 표시된다

- **WHEN** 사용자가 핀 생성 폼에서 미디어 파일을 업로드하고 메타 정보 영역이 렌더링될 때
- **THEN** 미디어 카테고리 라벨은 'tags, category labels' 카테고리 글자 크기로 표시된다
- **AND** 같은 영역의 파일명 · trim 정보 · 사이즈 비교 텍스트는 한 단계 위의 'creator name, meta' 카테고리 글자 크기로 표시된다
- **AND** 미디어 카테고리 라벨은 같은 영역의 다른 텍스트보다 명백히 작게 인지된다

#### Scenario: 미디어 카테고리 라벨 글자 크기 변경이 같은 영역 다른 텍스트에 회귀를 일으키지 않는다

- **WHEN** 미디어 카테고리 라벨 글자 크기가 'tags, category labels' 카테고리에 맞춰 조정될 때
- **THEN** 같은 메타 영역의 파일명 · trim 정보 · 사이즈 비교 텍스트 글자 크기는 변경되지 않는다
- **AND** 메타 영역 컨테이너의 flex 정렬 · 색상 · 간격은 변경되지 않는다
