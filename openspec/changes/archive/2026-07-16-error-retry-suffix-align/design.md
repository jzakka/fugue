# Design

## Context

`AddToBoardButton.tsx`의 `handleSelectBoard` catch 블록은 409(중복) 여부에 따라 메시지를 분기한다. 비중복 실패 메시지가 "보드 추가에 실패했습니다. 다시 시도해주세요"로, 같은 컴포넌트의 `handleCreateAndAdd` 실패 메시지("보드 생성에 실패했습니다")와 문형이 갈린다.

## Goals / Non-Goals

- Goal: 보드 추가 실패 메시지를 무접미 사실 서술형으로 정렬
- Non-Goal: 로그인 페이지 에러 카피(OAuth 리다이렉트 왕복 실패, 페이지 층위 경계) 변경 — 스코프 외
- Non-Goal: 409 분기 메시지, 보드 생성 실패 메시지 변경 — 이미 관례 부합

## Decisions

### Decision 1: 문자열 접미 제거 (단일 지점 수정)

`AddToBoardButton.tsx:200`의 fallback 메시지를 `"보드 추가에 실패했습니다. 다시 시도해주세요"` → `"보드 추가에 실패했습니다"`로 변경한다.

대안 — 공통 에러 카피 상수/헬퍼 추출: 13곳 카피가 대상 작업별로 모두 다른 명사구를 쓰므로 공통화 이득이 없고 스코프 초과. 기각.

### Risks

- 위험 낮음: 사용자 노출 문자열 1건. 로직/분기/스타일 무변경.
