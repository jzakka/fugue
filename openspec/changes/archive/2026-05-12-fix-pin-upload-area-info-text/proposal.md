## Why

pin 도메인 스펙은 핀 생성 폼의 파일 업로드 영역에 "허용 미디어 타입과 자동 최적화가 적용됨을 안내하는 텍스트"를 표시하도록 요구하지만, 현재 구현은 `이미지 / 오디오 / 비디오`라는 미디어 종류만 노출하고 자동 최적화에 대한 사용자 안내가 없다. 결과적으로 사용자는 어떤 형식이 허용되는지, 업로드 후 어떤 처리가 자동으로 일어나는지 인지하지 못한 채 파일을 선택한다.

## What Changes

- 핀 생성 폼의 파일 업로드 안내 영역에 허용 미디어 타입과 자동 최적화 적용 사실을 안내하는 텍스트를 표시한다.
