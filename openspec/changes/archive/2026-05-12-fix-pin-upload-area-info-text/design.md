## Context

핀 생성 폼(`apps/web/src/app/pin/new/PinCreateForm.tsx`)의 파일 업로드 안내 영역은 현재 "이미지 / 오디오 / 비디오"라는 미디어 종류만 노출한다. 스펙은 "허용 미디어 타입과 자동 최적화가 적용됨을 안내하는 텍스트가 표시된다"를 요구한다. 이 갭은 UI 텍스트 추가로 충족 가능하며, 동작 변경이나 새 모듈 도입이 필요 없다.

## Goals / Non-Goals

**Goals:**
- 파일 업로드 영역에 허용 미디어 타입과 자동 최적화 적용 사실을 안내한다.
- 안내 텍스트는 파일이 아직 선택되지 않은 dropzone 상태에서 보인다.

**Non-Goals:**
- 미디어 타입별 사이즈 한도 수치 노출. (구현 세부사항이며 시나리오가 요구하지 않는다.)
- 오디오/비디오 변환 파이프라인 변경.
- 클라이언트 검증 로직 변경.

## Decisions

- 안내 텍스트는 dropzone 내부의 보조 텍스트 영역에 인라인으로 추가한다. 별도 컴포넌트 분리 없이 처리한다. — 추가 추상화는 시나리오가 요구하지 않는다.
- "자동 최적화"라는 용어를 사용한다. 사용자가 어떤 처리를 거치는지 인지할 수 있으면 충분하며, 구체적 알고리즘은 스펙 외 정보다.

## Risks / Trade-offs

- [모바일 등 좁은 화면에서 텍스트가 길어 줄바꿈이 보기 싫게 일어날 수 있다] → 짧고 자연스러운 문구로 제한한다.
