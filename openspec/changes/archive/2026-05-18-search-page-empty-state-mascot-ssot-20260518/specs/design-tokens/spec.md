## ADDED Requirements

### Requirement: 빈 상태 위계 통일

페이지 본문 영역에 노출되는 빈 상태(empty state)는 사이트 전체에서 동일한 시각 위계 — 마스코트, 본문 메시지, 보조 부연 — 로 표시되어야 하며, 한 곳의 빈 상태가 다른 곳의 빈 상태와 vertical padding · 마스코트 크기 · 메시지/부연 위계가 다르게 보여서는 안 된다. 위계의 구체 카테고리는 디자인 가이드(DESIGN.md L14 '마스코트: 헤드셋 끼고 붓 든 복어. 로고/빈 상태/온보딩에서 활용.')의 마스코트 카테고리 명시를 따른다.

#### Scenario: 검색 페이지에서 검색어를 입력하지 않은 상태에 진입했을 때 빈 상태가 마스코트·메시지·부연 위계로 표시된다

- **WHEN** 사용자가 검색 페이지(`/search`)에 진입했고 검색어 파라미터(`q`)가 비어 있다
- **THEN** 화면 본문에는 마스코트(헤드셋 끼고 붓 든 복어) + 본문 메시지("검색어를 입력해주세요") + 보조 부연("작품, 크리에이터, 보드를 검색할 수 있습니다")이 세 단계 위계로 표시된다

#### Scenario: 빈 상태의 vertical padding이 다른 페이지의 빈 상태와 동일하다

- **WHEN** 사용자가 사이트 내 임의의 페이지 본문 빈 상태(피드/검색 결과 없음/보드 빈 상태/마이페이지 빈 상태 등) 중 어느 곳을 보든
- **THEN** 빈 상태 컨테이너의 vertical padding은 모든 위치에서 동일하게 렌더링되어, 한 곳만 더 위·아래로 늘어나거나 좁아져 보이지 않는다

#### Scenario: 새 빈 상태 표시 위치가 추가될 때 동일 위계로 통일된다

- **WHEN** 코드 SSoT에 페이지 본문 빈 상태를 노출하는 새 위치가 추가되거나 기존 위치의 인라인 마크업이 수정된다
- **THEN** 해당 위치는 마스코트·메시지·부연 위계를 따르는 빈 상태 표시 SSoT를 경유하여 다른 위치와 동일한 시각 위계로 렌더링된다
