## MODIFIED Requirements

### Requirement: 보드를 수정한다
시스템은 보드 소유자만 보드를 수정할 수 있어야 한다(SHALL).

#### Scenario: 소유자가 보드 이름 수정
- **WHEN** 소유자가 보드 이름 변경을 요청하면
- **THEN** 보드 이름이 업데이트된다

#### Scenario: 소유자가 공개 여부 변경
- **WHEN** 소유자가 보드의 공개 설정을 변경하면
- **THEN** 공개 여부가 업데이트된다

#### Scenario: 소유자가 아니면 수정 불가
- **WHEN** 소유자가 아닌 유저가 보드 수정을 요청하면
- **THEN** 권한 오류가 반환된다

#### Scenario: 수정 후 보드 정보 조회가 실패한 경우
- **WHEN** 보드 수정 자체는 성공했으나 응답 조립을 위한 보드 정보(`pin_count`/`cover_images`) 조회가 결정적으로 실패한 경우
- **THEN** 서버는 잘못된 값(예: 0/빈 목록)을 응답하지 않고 에러를 반환한다 (응답 정확성을 묵시 zero value로 우회하지 않도록 fail-closed)

---

### Requirement: 유저의 보드 목록을 조회한다
시스템은 유저의 보드 목록을 제공해야 한다(SHALL).

#### Scenario: 본인의 보드 목록
- **WHEN** 인증된 유저가 자신의 보드 목록을 조회하면
- **THEN** 공개 + 비공개 모든 보드가 반환된다

#### Scenario: 타인의 보드 목록
- **WHEN** 다른 유저의 보드 목록을 조회하면
- **THEN** 공개 보드만 반환된다

#### Scenario: 목록 내 보조 정보 조회가 실패한 경우
- **WHEN** 보드 목록 안의 한 보드에 대한 보조 정보(`pin_count`/`cover_images`) 조회가 결정적으로 실패한 경우
- **THEN** 서버는 해당 보드만 잘못된 값으로 표시한 부분 응답을 반환하지 않고 에러를 반환한다 (목록 가용성을 잘못된 값으로 우회하지 않도록 fail-closed)
