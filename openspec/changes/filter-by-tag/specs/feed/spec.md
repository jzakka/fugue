## ADDED Requirements

### Requirement: 피드 페이지에서 태그 필터를 제공한다
시스템은 메인 피드 페이지에서 인기 태그 목록을 서버 사이드로 로드하여 태그 필터 UI를 렌더링해야 한다(SHALL).

#### Scenario: SSR 시 인기 태그와 핀을 병렬 로드
- **WHEN** 메인 페이지를 서버 사이드 렌더링하면
- **THEN** 인기 태그 목록과 초기 핀 목록이 병렬로 fetch되어 함께 렌더링된다

#### Scenario: 태그 파라미터가 있는 페이지 요청
- **WHEN** `?tags=태그1,태그2` 쿼리 파라미터가 포함된 페이지를 요청하면
- **THEN** SSR 시 해당 태그로 필터링된 초기 핀이 렌더링된다

#### Scenario: 인기 태그 로드 실패
- **WHEN** 인기 태그 API 호출이 실패하면
- **THEN** 태그 필터 UI가 표시되지 않고, 핀 목록은 정상적으로 표시된다

---

### Requirement: 메인 피드에서 태그로 필터링한다
사용자는 메인 피드 페이지에서 인기 태그 칩을 선택하여 해당 태그가 포함된 핀만 볼 수 있어야 한다(SHALL).

#### Scenario: 단일 태그 선택
- **WHEN** 사용자가 태그 칩 하나를 선택하면
- **THEN** 해당 태그가 포함된 핀만 피드에 표시된다

#### Scenario: 다중 태그 선택 (OR)
- **WHEN** 사용자가 태그 칩 여러 개를 선택하면
- **THEN** 선택된 태그 중 하나라도 포함된 핀이 표시된다

#### Scenario: 태그 선택 해제
- **WHEN** 이미 선택된 태그 칩을 다시 클릭하면
- **THEN** 해당 태그 필터가 해제되고 피드가 갱신된다

#### Scenario: 전체 초기화
- **WHEN** 태그가 하나 이상 선택된 상태에서 초기화 버튼을 클릭하면
- **THEN** 모든 태그 필터가 해제되고 전체 피드가 표시된다

#### Scenario: 분야 필터와 조합
- **WHEN** 분야 필터와 태그 필터를 동시에 적용하면
- **THEN** 두 조건을 모두 만족하는 핀만 표시된다 (AND 관계)

#### Scenario: 태그 필터 상태 URL 유지
- **WHEN** 태그를 선택한 상태에서 URL을 복사하여 공유하면
- **THEN** 수신자가 해당 URL로 접속 시 동일한 태그 필터가 적용된 피드를 볼 수 있다

#### Scenario: 태그 변경 시 페이지네이션 초기화
- **WHEN** 무한 스크롤 중 태그 필터를 변경하면
- **THEN** 피드가 첫 페이지부터 다시 로드된다
