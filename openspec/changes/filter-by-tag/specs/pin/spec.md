## ADDED Requirements

### Requirement: 인기 태그 목록을 조회한다
시스템은 전체 핀에서 가장 많이 사용된 태그를 집계하여 제공해야 한다(SHALL).

#### Scenario: 인기 태그 조회
- **WHEN** 인기 태그 목록을 요청하면
- **THEN** 사용 빈도 내림차순으로 태그와 사용 횟수가 반환된다

#### Scenario: 조회 개수 제한
- **WHEN** limit 파라미터를 지정하여 인기 태그를 요청하면
- **THEN** 최대 해당 개수만큼 반환된다 (기본값 20, 최대 50)

#### Scenario: 핀이 없는 경우
- **WHEN** 시스템에 핀이 하나도 없을 때 인기 태그를 요청하면
- **THEN** 빈 배열이 반환된다
