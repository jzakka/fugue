# OpenSpec 피쳐 현황

도메인 스펙 기준으로 전체 기능과 구현 상태를 체크리스트로 출력하라.

## 참조 파일

1. `openspec/specs/*/spec.md` — 도메인별 스펙 (이것이 기준)
2. 실제 코드를 읽어서 구현 여부 확인:
   - `apps/api/internal/` — 백엔드 핸들러
   - `apps/web/src/` — 프론트엔드 페이지/컴포넌트
   - `apps/api/cmd/server/main.go` — 라우트 등록

## 출력 형식

도메인(스펙)별로 Requirement를 나열하고, 각 Requirement의 Scenario별 구현 상태를 체크.

```
## 피쳐 현황

### pin
- [x] 외부 URL을 핀으로 저장한다
  - [x] 유효한 핀 생성
  - [x] URL은 필수이다
  - [ ] 미디어 파일은 필수이다 ← 미구현
  ...
- [x] 핀 목록을 필터링하여 조회한다
  ...

### board
...
```

## 규칙

- `[x]` = 해당 시나리오를 충족하는 코드가 백엔드+프론트엔드에 존재
- `[~]` = 부분 구현 (한쪽만 있거나 불완전)
- `[ ]` = 미구현
- 스펙에 없지만 코드에 존재하는 기능은 "스펙 외 구현" 섹션에 표시
- 마지막에 도메인별 요약 테이블: 도메인 | 전체 Requirement | 구현 | 부분 | 미구현
