# OpenSpec 태스크 현황

아카이브되지 않은 활성 change들의 태스크 진행 상황을 출력하라.

## 참조 파일

1. `openspec/changes/` — 활성 change 디렉토리 (archive/ 제외)
2. 각 change의 `tasks.md` — 체크박스 태스크 목록
3. 각 change의 `proposal.md` — 변경 요약 (무엇을/왜)

## 절차

1. `openspec/changes/`에서 디렉토리를 순회하되, `archive/`는 제외
2. 각 change의 `tasks.md`를 읽고 `- [ ]`, `- [x]` 상태를 파싱
3. 실제 코드를 확인하여 `[x]`로 표시된 태스크가 정말 구현됐는지 검증

## 출력 형식

```
## 활성 Changes

### pin-media-pivot
> 핀 모델을 Pinterest 방식으로 전환 (미디어 필수, 사전정의 태그)

| 그룹 | 전체 | 완료 | 진행률 |
|------|------|------|--------|
| 1. 스토리지 인프라 | 3 | 0 | 0% |
| 2. DB 마이그레이션 | 4 | 0 | 0% |
| ... | | | |
| **합계** | **19** | **0** | **0%** |

미완료 태스크:
- [ ] 1.1 docker-compose에 MinIO 서비스 추가
- [ ] 1.2 Go API에 S3 클라이언트 모듈 추가
...
```

활성 change가 없으면 "활성 change 없음" 표시.

## 규칙

- `[x]` 표시된 태스크도 코드가 실제로 없으면 `[~]` (체크 불일치)로 표시
- 각 change의 proposal.md 첫 문단을 인용하여 맥락 제공
- 여러 change가 있으면 우선순위/의존성 순서대로 나열
- 한국어로 출력
