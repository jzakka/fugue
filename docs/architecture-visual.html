Security

⚠ SSRF Protection

  • http/https schemes only
  • Custom DialContext + DNS resolve
  • Private IP block (10.x, 172.16-31.x, 192.168.x, 127.x, ::1)
  • Max 5 redirect hops, re-verify each
  • 1MB response limit, 5s timeout

🔒 Auth & Authz

  • JWT HMAC-SHA256
  • Access: 15min, Refresh: 7d + rotation
  • Pin delete: WHERE creator_id = $2
  • Board: owner verification
  • Private boards: owner only

⚡ Rate Limiting

  • Pin creation: 30/min/user
  • OG fetch: 20/min/IP
  • Auth login: 10/min/IP
  • Auth callback: 5/min/IP
  • Redis fixed-window, fail-open

✓ XSS Prevention

  • React auto-escaping only
  • No dangerouslySetInnerHTML
  • OG data rendered via JSX props
  • Security headers (X-Frame-Options, X-Content-Type-Options)
