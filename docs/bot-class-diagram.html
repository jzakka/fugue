Pioneer 와 Harvester 는 동일한 URLScheduler 인터페이스를 통해 Postgres frontier (PGURLScheduler) 위에서 분리된 큐를 소비합니다. Pioneer 의 fetch 경로는 ConsumerFetcher, Harvester 의 fetch 경로는 스냅샷 우선 합성 SnapshotFirstFetcher (ObjectStorage + HTTP 두 Fetcher) 로 분리됩니다. 추출/분류/영속화 책임은 AdapterRegistry · GenericExtractor · Classifier · MediaValidator · DocumentPipeline 로 인터페이스 단위로 쪼개져 있습니다.
