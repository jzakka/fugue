# Spec: Board (보드)

핀을 주제별로 묶는 컬렉션. Pinterest 보드와 동일한 컨셉.

## 요구사항

### 보드 CRUD

- REQ-B-001: 인증된 사용자는 이름(필수)과 설명(선택)으로 보드를 생성할 수 있다
- REQ-B-002: 보드 이름은 100자 이내여야 한다
- REQ-B-003: 보드 소유자는 이름, 설명, 공개 여부를 수정할 수 있다
- REQ-B-004: 보드 소유자는 보드를 삭제할 수 있다
- REQ-B-005: 보드에 공개/비공개 설정이 있다 (기본값: 공개)

### 보드-핀 관계

- REQ-B-010: 보드 소유자는 보드에 핀을 추가할 수 있다
- REQ-B-011: 보드 소유자는 보드에서 핀을 제거할 수 있다
- REQ-B-012: 같은 핀을 같은 보드에 중복 추가할 수 없다 (멱등)
- REQ-B-013: 하나의 핀은 여러 보드에 소속될 수 있다

### 보드 조회

- REQ-B-020: 공개 보드는 누구나 조회할 수 있다
- REQ-B-021: 비공개 보드는 소유자만 조회할 수 있다
- REQ-B-022: 보드 상세 조회 시 보드 메타데이터와 소속 핀 목록을 함께 반환한다
- REQ-B-023: 보드 소속 핀 목록은 페이지네이션을 지원한다
- REQ-B-024: 크리에이터의 보드 목록을 조회할 수 있다 (본인이면 전체, 타인이면 공개만)

### 보드 탐색

- REQ-B-030: 크리에이터 프로필 페이지에서 해당 크리에이터의 공개 보드 목록을 볼 수 있다
- REQ-B-031: 핀 상세 페이지에서 해당 핀이 소속된 공개 보드 목록을 볼 수 있다
- REQ-B-032: 보드 목록의 각 보드를 클릭하면 보드 상세 페이지로 이동한다
